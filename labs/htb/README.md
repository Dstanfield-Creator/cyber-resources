# HackTheBox Tracker

> **Status:** Active
> **Updated:** 2026-09-04

Tracking index for HackTheBox machines worked through on `hackerv1`.

## How to use this

1. Connect to the HTB VPN from hackerv1: `sudo openvpn --config ~/htb/vpn/<file>.ovpn` (run it inside `tmux new -s vpn` so it stays up).
2. Copy [`_template.md`](./_template.md) to `<machine-name>.md` in this folder and fill it in as you go.
3. Add a row below when a box is started; update it when finished.
4. Do not publish real flag values, and only publish full write-ups for **retired** HTB machines
   (per HTB's terms) — this repo is public on GitHub. Keep flags redacted (`***REDACTED***`) always.
