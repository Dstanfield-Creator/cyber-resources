# Labs

Hands-on practice environments and write-ups: the Ludus cyber range the detections are tested against, HackTheBox machines, and other lab exercises.

## Structure

- `ludus-cyber-range/` — reproducible Active Directory attack / detection range on Proxmox (router, Server 2022 DC, Win 11 workstation, Kali), rebuilt from YAML. See [ludus-cyber-range/README.md](./ludus-cyber-range/README.md).
- `htb/` — HackTheBox machine write-ups. See [htb/README.md](./htb/README.md) for the tracker
  and [htb/_template.md](./htb/_template.md) for the write-up template.
